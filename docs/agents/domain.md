# Domain Docs

Single-context repo.

## Before exploring, read these

- `CONTEXT.md` at the repo root
- `docs/adr/` when it exists

If a file is missing, proceed silently. `/domain-modeling` creates them when a term or ADR actually lands.

## Use the glossary's vocabulary

When output names a domain concept, use the term as defined in `CONTEXT.md`. Don't drift to synonyms listed under `_Avoid_`.
