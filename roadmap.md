# Roadmap

What matters **this week**. Not a five-year plan.

## Current goal

A localhost Plant of the Day page someone would send to a friend: Kinfolk look, How Many Plants voice, Head Gardener on the byline.

## This week

Greg’s 7-day loop, adapted. Do one day at a time.

1. **Repo brain** — workspace files live; read `context/working-style.md`, this file, `review.md`, `spec/` before editing product.
2. **Plan mode** — one small product task; inspect the prototype first; output plan, file list, risks, verification.
3. **One visible improvement** — Cover stays quiet; next depth (Closer / Ledger / Practice / Questions / Stories) gets sharper on Aloe.
4. **Preview** — desktop + narrow viewport at `http://localhost:8081/prototype/daily-page/`.
5. **Review** — diff against `review.md`.
6. **Show someone** — send the localhost page (or a Loom) to people who might care. Replies go in `customers/`.
7. **Morning brief** — run `routines/morning-brief.md`; recommend one build task.

Plant list stays in `data/plants.json`. Phil / the Head Gardener write plants. We do not invent a list factory.

## Out of scope

- Public suggest / vote / leaderboard
- Firebase, production host, accounts
- Merch, mailing list, iOS
- Green-thumb scores, HMP icon grids, a blog mill
- A curator CMS
- Generating an article per plant just to fill Stories

## Definition of done (this week)

- First fold is only date, common name, latin, photo
- Note sounds like a person, not a care sheet
- Aloe shows all five depths on scroll
- `http://localhost:8081/prototype/daily-page/` still runs
