# Walkthrough — localhost daily page

1. Open http://localhost:8081/prototype/daily-page/
2. Cover: only Aloe, latin, date, photo plate. If you see water/light here, the Cover is broken.
3. Scroll: Note, then also-known-as / origins, then Head Gardener.
4. Scroll: Ledger lines.
5. Scroll: Practice, then Questions.
6. Arrow keys: variants A (magazine), B (field notebook), C (specimen).
7. Say the line you’d send a friend. If there isn’t one, the Note failed.

Do not demo the client area (`:8080`) as the product. That is the project hub.
