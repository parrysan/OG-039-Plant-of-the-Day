# Working style

Greg’s `CLAUDE.md` job: how the employee works. The repo’s `CLAUDE.md` stays `@AGENTS.md` (OS rule). Read this file instead.

## How to work

- Small, reviewable changes. One concern per commit.
- If the change affects what a visitor sees, state the plan first and wait.
- Stay on `roadmap.md`. Do not start a second stream.
- Match existing HTML/CSS. Do not invent a new visual system.
- After a change: open `http://localhost:8081/prototype/daily-page/`, check desktop and a narrow viewport, then summarise what changed, what you checked, and what a human must look at.

## Business (one line)

One plant a day, written with a named Head Gardener. Looks like Kinfolk. Reads like How Many Plants’ “About the plant”. The link still works tomorrow.

## Quality bar

- Cover is clear in five seconds: date, common name, latin, photo.
- Note is one sentence someone would paste to a friend.
- Words from `customers/language.md`. No slop, no thumbs, no SaaS hero.
- Localhost only. No Firebase. No deploy.
