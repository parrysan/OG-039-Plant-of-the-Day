# Routine — pull request review

When a PR opens, review it using `review.md`.

Comment only on:

- bugs
- broken visitor flows (Cover growing extra chrome, depths out of order)
- security
- confusing behaviour

Then post a short summary:

- what looks good
- what needs attention
- ready for human review? yes / no

Do not rewrite the PR. Do not merge if the Cover is no longer minimal.
